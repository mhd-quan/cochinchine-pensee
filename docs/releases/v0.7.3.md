# v0.7.3 — Title weight and delivery performance

Published essay titles now use the real Playfair Display SC 700 face across
cards, archives, search results and reader navigation, while muted coming-soon
and discovery labels retain their lighter treatment. The homepage and essay
lists preload only the title weight they use.

Mobile discovery images now cap their candidate variants at 672px, while the
desktop image set remains unchanged. Author counts use screen-reader text rather
than a prohibited ARIA label.

Google Analytics keeps the initial visit in the data layer immediately, then
loads its third-party runtime after the first paint or when navigation/page
visibility requires it. The loader is idempotent and tested for quick Astro
navigation, cancelled transitions and hidden pages.

Verification: 38 automated tests pass, Astro check reports zero errors and
warnings, the production build produces 82 pages, focused lint passes, and the
local Lighthouse comparison reduced mobile transfer by about 56 KB while moving
Accessibility from 97 to 100. Lighthouse results remain variable under network
throttling; the production PageSpeed baseline was 97 desktop and 72 mobile.
