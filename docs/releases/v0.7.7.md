# v0.7.7 — Reader actions and end-of-article navigation

The action row now follows the article text inside the reading column, rather than the separate footer after the entire sidebar. This keeps Facebook, X, Copy, Email and PDF next to the end of the essay on both desktop and mobile, before the mobile reader companion.

Facebook and X are first-party buttons that open their encoded sharing destinations only after activation. They retain the official monochrome marks and provide ordinary links when JavaScript is disabled. Component-specific action classes replace the generic share-links container. The reported missing social controls were not reproducible in the inspected production browser; these changes remove the generic container and direct social-link selectors from the active controls, but cannot guarantee behavior under arbitrary browser content filters. No social SDK or additional dependency is introduced.

Desktop reading preferences keep their existing position. The companion below them follows the article with bounded sticky positioning, returning to its original place beneath the preferences when scrolling back up. Its offset accounts for its actual height on shorter screens, without creating a nested scroll area.

A return-to-top button is hidden until the bottom of the article text reaches the viewport. It remains available below the article, hides again when scrolling back above its end, and resets on Astro navigation. Activation scrolls to the page top and transfers keyboard focus to the essay heading; reduced-motion preferences are respected. On desktop it sits at bottom left. On mobile Aa stays bottom left and the return control sits symmetrically at bottom right, both 48 px; the return control hides while the settings sheet is open.

Validation: Astro check has 0 errors and 0 warnings (44 existing hints). The production build generates 82 pages and 58 image-only PDFs. All 46 tests pass, including end-of-article visibility, reduced motion, navigation cleanup and single-activation platform handlers. Browser checks covered desktop and mobile action rows, initial/mid/end reading states, return-to-top focus and scrolling, companion stacking and article navigation. Essay sources, metadata profiles and PDF rendering code are unchanged. This release also carries the v0.7.6.1 secondary-logo patch into the release integration branch.
