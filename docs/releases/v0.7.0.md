# v0.7.0 — Navigation, search and series

## Before / after

| Area | Before | v0.7.0 |
| --- | --- | --- |
| Navigation | Scroll-driven size/direction changes and inconsistent label weights | Stable compact reading bar activated by an intersection observer; 12px, 600-weight navigation labels |
| Menu underline | Hairline treatment | 2px crimson rule, 0.45em offset, 140ms transform transition |
| Hamburger | Oversized title and navigation | Logo remains in the masthead; menu attaches directly below it, with a search field first, 12px peer links and 44px+ controls; 240ms entrance and 180ms exit |
| Search | No site search | Form slides left-to-right within exactly the masthead/banner height; embedded menu search on mobile; a dedicated results page supports Vietnamese accented/accentless and English queries |
| Newsletter | English explanatory copy | “Nhận thông tin bài viết mới”, with the English Substack CTA |
| Footer | 14px navigation, 30–42px newsletter heading | 12px navigation, 20–24px newsletter heading, 20px wordmark |
| Page intros | Counts and explanatory subtitles under archive/directory headings | Heading and content without the extra meta commentary; editorial article subtitles retained |
| Homepage series | Four vertically repeated series modules | One scroll-snap carousel, selector and previous/next controls; three compact article rows on mobile |
| Loading | One blocking stylesheet request | Inline styles, independently cached fonts and responsive images, on-demand search index |

Typography and masthead search placement were compared with
[Claremont Review of Books](https://claremontreviewofbooks.com/). The publication's
existing fonts, paper/ink/crimson palette and article typography remain in place.
Muted metadata ink is darkened for small-text contrast.

## Validation

- 80 static pages built, including 58 indexed published essays.
- Astro check: zero errors, zero warnings; 18 automated checks pass.
- Real built search tests cover accented and accentless Vietnamese, English title
  ranking, punctuation/empty queries and nonexistent words. Search metadata and
  exclusion of navigation pages are verified against the generated output.
- Responsive image dimensions/candidates, article-only reader preferences, SEO,
  canonical URLs and footer destinations remain covered by the existing tests.
- Browser verification includes desktop masthead/search/menu and 320/390px mobile
  viewports: no horizontal overflow, menu/search keyboard focus, Escape close,
  series controls/selection and footer. Mobile series panels reserve equal height.
- Desktop header and main-content positions remain unchanged when search opens
  (132px logo/banner footprint). On mobile, the menu top aligns with the 64px
  masthead bottom. Search uses a shared magnifying-glass SVG, 12px uppercase labels,
  lighter placeholders and an underline focus cue instead of an input rectangle.
- Search code handles IME input, cancels stale responses, supports retry, and
  loads only result fragments being shown. No animation/carousel dependency added.

## Performance evidence

The production v0.6.5 baseline measured on September 5 in PageSpeed Insights:
[mobile report](https://pagespeed.web.dev/analysis/https-cochinchinepensees-studio/ipcgnr456l?form_factor=mobile).
Performance 79; FCP 3.0s; LCP 4.4s; TBT 60ms; CLS 0.003; accessibility 96;
best practices and SEO 100. This is a single simulated slow-4G lab run, not field
Core Web Vitals. The report has no field data.

The baseline homepage transfers roughly 15.7 KB gzipped HTML plus 7.5 KB shared
CSS. v0.7.0 transfers roughly 25.1 KB gzipped HTML and has no blocking stylesheet
request. This exchanges a small repeat-navigation HTML cost for earlier rendering
on a cold connection. Search index/WASM bytes are absent from initial page loading.
Fonts and images keep their existing hashed cache strategy. The mobile series
cards request 96px-wide thumbnails instead of full-width covers.
