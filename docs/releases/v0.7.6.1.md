# v0.7.6.1 — Facebook secondary mark

The reader now uses the monochrome Secondary Logo from the editor-supplied Facebook Brand Asset Pack. Its single vector path is extracted from the Illustrator file, retaining the transparent f cutout. It is black on light reader themes and white on Night, including hover states.

The mark is 20 × 20 px inside the existing 44 × 44 px touch target. Cropping the Illustrator artboard margin through the viewBox does not change the artwork; the button retains 12 px clear space on each side. Inline SVG markup drops from 794 to 521 bytes (34%); isolated gzip size drops from 461 to 348 bytes. No asset request, raster image or client JavaScript is added.

Converted with Poppler and optimized with SVGO at three decimal places.
