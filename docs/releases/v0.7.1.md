# v0.7.1 — Single-row search and font loading

## Before / after

| Area | v0.7.0 | v0.7.1 |
| --- | --- | --- |
| Desktop TCP column | 72px, tied to the control width | 100px, with the search field, close glyph and hamburger centered on the same row |
| Header and mobile search | Visible “Tìm kiếm” label above “Tìm bài viết…” | One field reading “TÌM KIẾM…”; the accessible label remains available to screen readers |
| Search typography | Two stacked lines | One 12px, regular-weight uppercase placeholder; input remains 16px to avoid iOS focus zoom |
| Font loading | Overlapping Latin Extended and Vietnamese ranges | Disjoint ranges based on actual font character maps; Vietnamese characters belong to the compact Vietnamese subset |
| Critical font discovery | Fonts discovered during layout | Wordmark and relevant heading fonts preloaded from the HTML, using the exact CSS asset URLs |
| Small-screen newsletter | Font-dependent flex wrapping | Explicit two-row layout below 512px so font swapping cannot change its row count |

The 132px desktop masthead/banner search footprint and left-to-right slide are
preserved. Mobile search stays inside the menu, directly below the masthead.
The original typefaces, weights, OpenType features, and full publication character
coverage remain intact. Latin Extended, Greek and Cyrillic remain available when
content needs them. The font parsing dependencies already used transitively by
the build are now declared explicitly; no new library ships to the browser.

## Validation

- Production build: 80 pages, 58 indexed essays.
- 21 automated checks pass, including real font coverage, disjoint Unicode ranges,
  preload/CSS URL reuse, Vietnamese search, responsive images, reader preferences
  and SEO. Astro check reports zero errors and zero warnings.
- Browser checks: 100px TCP column; 132px header footprint; aligned search/close/menu
  controls; keyboard search and Escape; embedded mobile search with its top at the
  masthead bottom; accented and accentless results.

## Performance baseline

The [user-supplied mobile report](https://pagespeed.web.dev/analysis/https-cochinchinepensees-studio/8osewnm2h2?form_factor=mobile)
measured v0.7.0 at 89 performance, FCP 2.0s, LCP 3.2s, TBT 200ms and CLS 0.006.
Accessibility, best practices and SEO were 100. Its dependency tree contains
20 font requests and a maximum critical path of 866ms, ending at Cloudflare RUM.
These are simulated slow-4G lab results; the report has no field Core Web Vitals.

Fonts remain self-hosted and independently cacheable. Styles stay inline; search
index/WASM remains absent from the homepage. No additional preconnect is added:
the report identifies no useful candidate origin.
