# v0.9.1 — Publication essentials

Based on `2a5f95c` (the merged v0.9.0 review on `main`).

## Changes

- Supply the missing 1200 × 630 publication sharing card. The previous production
  `/og-default.png` returned 404. Article covers remain the article share image;
  pages without covers get the publication card and a matching alternative.
- Require explicit page descriptions. Validate unique titles/descriptions,
  Open Graph consistency, share-image availability, favicon assets and rendered
  image dimensions/alternatives across every built HTML page.
- Make About indexable; add an indexable Privacy page and footer Privacy/Contact
  links. Both information pages use one small layout derived from the existing
  About page. The existing editorial email is also visible on About.
- Describe the actual GA4, browser reading preferences, Cloudflare and Substack
  behavior. No new analytics, consent library, newsletter form or sticky CTA.
- Describe 72 visually reviewed illustration sources in a build-only catalogue.
  Existing meaningful frontmatter/Markdown alternatives take precedence. Inline
  images without a reviewed alternative now fail the build. Essay prose and
  editorial source-review hashes are unchanged.
- Use generic page-not-found wording for the custom 404. Preserve real HTTP 404
  responses, noindex and navigation back to the publication.
- Fix a reproduced search retry failure: browsers retain failed dynamic imports,
  so resetting a Promise alone did not re-request Pagefind. Only failed engine
  loads advance a retry URL; successful loads remain shared and on demand.

## Delivery cost and measurements

Homepage HTML remains below the existing 200,000-byte raw / 30,000-byte Brotli
budgets. The share PNG is 29,337 bytes and is referenced only by metadata.
The eight browser JavaScript chunks total 29,655 bytes versus 29,618 before
(+37 bytes, for search retry). The image description catalogue is 20,586 source bytes and is never shipped as
an entire browser module. Only the descriptions needed for the rendered content
or an on-demand discovery response are included.

Local comparisons use Chrome, disabled browser cache, 4× CPU slowdown, 170ms
latency and 9 Mbps download. Desktop uses 1440 × 1000; mobile 390 × 663 at DPR 3.
The optional external-script run permits GA4 on the local preview; it does not
reproduce Cloudflare's production injection/security layer. Medians are lab
observations, not field Core Web Vitals or guaranteed device-wide timings.

Homepage HTML: 196,465 → 198,364 raw bytes; 23,409 → 23,960 Brotli bytes.
